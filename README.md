# 📁 NodeFS Manager

A powerful CLI-based File System Manager built with Node.js that allows users to create, edit, delete, and manage files and folders directly from the terminal.

---

## ✨ Features

* 📂 Create folders
* 📄 Create files
* ✍️ Write content to files
* 🗑️ Delete files
* 🧹 Delete folders
* 📋 List directory items
* 🎨 Colored terminal interface using Chalk

---

## 🛠️ Tech Stack

* Node.js
* Chalk
* Readline Promises API
* File System (fs/promises)

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/NodeFS-Manager.git
```

Move into the project folder:

```bash
cd NodeFS-Manager
```

Install dependencies:

```bash
npm install
```

---

## ▶️ Run the Project

```bash
node index.js
```
